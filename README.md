# MFC Youth Area Management System Web

Cloud-based web application for managing Area Members, Chapters, Services, Events, and GIG contributions.

## Tech Stack
- **Frontend**: Vanilla HTML / CSS / JavaScript
- **Backend**: Node.js (Vercel Serverless Functions)
- **Database**: Supabase (PostgreSQL)

## Getting Started
1. Clone the repository.
2. Navigate to the `Backend` folder and run `npm install`.
3. Set up your `.env` with Supabase credentials.
4. Run `vercel dev` for the backend.
5. Serve the `Frontend` folder using any local web server (e.g., Live Server).
