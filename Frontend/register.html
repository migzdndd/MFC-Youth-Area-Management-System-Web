Member Access

First-Time Access

Regular Member accounts are created when an authorized Servant Leader adds the Member's Gmail address to the database. Members do not need a password; access uses a real one-time code sent to that Gmail account.

How member access works Gmail address → verification code → Member Portal
  1. An authorized Servant Leader adds you to the Members database using your Gmail address.
  2. The system creates your linked Member account using your Gmail address.
  3. A real one-time verification/sign-in code is sent to that Gmail account.
  4. Enter the code when prompted to securely open your Member Portal.
  5. A password is optional. You may add one later, but it is never required for Member access.

Regular Members do not create an unlinked account first. A Servant Leader creates the official Member record with the Member Gmail address, and email-code verification securely links access to that record.

Not yet in the database? Contact an authorized Servant Leader.
Servant Leader Access

Register an Admin Account

For Couple Coordinators, Area Servants, LIT Servants, Chapter Servants, and other approved leadership access only. Your Gmail address must be verified with a one-time code before the account is created.

Create Account

This private registration code verifies that the person requesting leadership access is approved. Gmail OTP verification separately proves ownership of the email address.

Verify your Gmail account

A one-time verification code will be sent to your Gmail address before this account can be created.

Two checks are required The Administrator Registration Code authorizes leadership registration. The Gmail OTP proves that you own the email address. Your chosen Account Password becomes your normal login password after OTP verification succeeds.
After the Gmail OTP is verified, the account is created and you will choose or create your Area. No temporary password is issued.
