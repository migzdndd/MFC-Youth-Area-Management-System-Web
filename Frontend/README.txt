MFC Youth Area Management System - Web Prototype

HOW TO RUN
1. Keep all files/folders together.
2. Open index.html in a browser, or use VS Code Live Server.
3. Demo login: admin@mfcyouth.local / admin123
4. You may also create a demo account from register.html.

WHAT WORKS
- Login/register demo session
- Dashboard counts
- Members CRUD + service assignment + GIG tracker
- Chapters CRUD + chapter-member view
- Seven built-in service roles
- Activity Reports CRUD, filters, analytics, browser Print/PDF
- Events CRUD + participant registration/payment/attendance
- Responsive desktop/mobile layout
- Browser localStorage persistence

IMPORTANT
This is a functional FRONTEND/OFFLINE WEB PROTOTYPE. Data is stored in your browser with localStorage.
It is not yet connected to the WinForms SQLite database, cloud API, Vercel database, or production authentication.
The code is structured so those pieces can replace the browser data layer later.

SOURCE BASIS
The website structure follows the existing MFC Youth Area Management System modules: Dashboard, Members, Chapters, Services, Activity Reports, Events, participant registration, and GIG tracking.
