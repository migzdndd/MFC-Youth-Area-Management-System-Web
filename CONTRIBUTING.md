# Contributing

Thank you for contributing to the MFC Youth Area Management System Web!

## How to Contribute
1. **Report Bugs:** Open an issue with a clear description and steps to reproduce. (For security bugs, see `SECURITY.md`).
2. **Suggest Features:** Open an issue outlining your enhancement and why it is useful.
3. **Submit Code:** 
   - Fork the repository.
   - Create a branch from `main`.
   - Make your changes and test them locally.
   - Submit a Pull Request.

Please ensure your code aligns with the project's existing style.
